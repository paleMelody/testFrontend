# 24小时时间刻度盘

基于 **Vue 3 + Vite** 构建的双页面前端应用，包含 24 小时时间刻度盘（第一页）与 8 小时滚动时间窗口（第二页）。

---

## 环境要求

| 工具 | 推荐版本 |
|------|----------|
| [Node.js](https://nodejs.org/) | 18 及以上 |
| npm | 随 Node.js 附带 |

---

## 如何运行

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

启动后终端会显示本地访问地址，默认为：

```
http://localhost:5173
```

用浏览器打开该地址即可查看应用。

### 3. 构建生产包

```bash
npm run build
```

产物输出至 `dist/` 目录。

### 4. 预览生产包

```bash
npm run preview
```

本地预览 `dist/` 目录中构建好的文件，默认端口 `4173`。

## 页面说明

### 第一页 — 24 小时时间刻度盘（`/`）

- 左右各有一段约 **240°（2/3 圆弧）** 的时间刻度弧线。
- 左弧：**01:00 – 12:00**（共 12 个刻度），右弧：**13:00 – 00:00**（共 12 个刻度）。
- 每个刻度有一个可点击的发光圆点，旁边显示时间标签。
- 中间区域每行对应一个小时，左右各有一个**横向滚动框**，框内包含多个可配置样式的小窗口。
- 点击任意时间圆点，跳转到第二页，以该时刻为起始时间。

### 第二页 — 8 小时时间窗口（`/detail/:hour`）

- 同时展示 **8 个小时**的时间刻度（左弧 4 个 + 右弧 4 个）。
- 左上角显示起始时间（绿色），右下角显示终止时间（橙色），超过零点自动轮询（模 24）。
- 页眉实时显示当前时间段范围，例如 `06:00 → 14:00`。
- 在**左弧或右弧区域**上下**滚动鼠标滚轮**，可平移当前显示的时间窗口（±1 小时/格）。
- 点击弧线上的时间圆点可将窗口跳转到该时刻。
- 左上角 **← 返回** 按钮可回到第一页。

## 目录结构

```
src/
├── main.js                  # 应用入口
├── App.vue                  # 根组件（路由出口）
├── router/
│   └── index.js             # 路由配置（hash 模式）
├── views/
│   ├── Page1.vue            # 第一页：24 小时刻度盘
│   └── Page2.vue            # 第二页：8 小时窗口
├── components/
│   ├── ArcPanel.vue         # 可复用弧形刻度面板组件
│   └── TimeWindow.vue       # 可配置样式的小窗口卡片
└── composables/
    └── useArcPanel.js       # 弧线坐标计算 + 示例数据
```
